## 公交热救助小时分布

从 `资料/02_降温网络/Phoenix_Transit_Heat_Relief_FY21-22.csv` 按 `HOUR_OF_DAY` 汇总 `COUNT`，得到 [transit_hourly.csv](transit_hourly.csv)。原始表共 688 行、86 个运营日、12,830 人次，平均 149.2 人次/运营日。观测只覆盖 09:00–16:00；12 时最高（14.72%），16 时最低（10.30%），峰谷比 1.43。此数据只描述该公交热救助项目的日间使用，不能当作全市冷却中心需求，也不能验证 17 时后的需求分布。

## 解读边界

- 当前没有把人口、收入、热暴露分别映射为需求的独立机制；low/base/high 是综合需求情景，不是这些因素的单独因果效应。
- 20/30/45 分钟结果相同只说明本网络在这三个离散阈值下输出未变，不代表步行可达阈值不重要。
- 敏感性结果是现有合成规划网络与假设容量下的条件推演，不是实测因果结论。

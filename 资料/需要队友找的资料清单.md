## 一、最高优先级（缺了直接影响结论可靠性）

### 1. MAG 热避难网络站点目录 ⭐⭐⭐

**要什么**：Maricopa Association of Governments 的 Heat Relief Network 站点清单——每个站点的**名称、地址/坐标、类型（Respite / Cooling / Hydration / Donation）、开放时间**。形式不限：网页另存、PDF 传单、Excel、ArcGIS 导出、截图都行。

**入口**：
- 网页：https://azmag.gov/Programs/Community-Initiatives/Heat-Relief-Network
- ArcGIS 服务：https://geo.azmag.gov/arcgis/rest/services/maps/Heat_Relief_Network/MapServer
  （如果在浏览器能打开，把每层的 `?f=json` 另存，或 `?f=geojson&where=1=1&outFields=*` 下载就是完整数据）

**为什么重要**：我们现在的 22 个站点是**合成**的（区质心 + 假设容量）。有了真实目录，"网络缺口"才能从"模型内的"变成"现实中的"。

**已试过**：直连 403、代理 403、真实浏览器（Tabbit）打开时 **源站返回 522 超时**。
**所以**：如果你那边能打开，很可能是因为 MAG 源站恢复了，或者你的网络路径不同。

---

### 2. Valley Metro 公交 GTFS ⭐⭐⭐

**要什么**：Valley Metro 的 GTFS 数据包（`google_transit.zip` 或 `*.zip`），或者任何含**站点坐标 + 线路 + 时刻**的文件。

**入口**：
- https://www.valleymetro.org/ （找 "GTFS" / "Developer Resources" / "Open Data"）
- 也可试 https://transitfeeds.com/ 搜 "Valley Metro"（第三方镜像，往往不需翻墙）

**为什么重要**：我们现在的行程时间是**直线距离 × 1.35 ÷ 速度**，会**系统性低估**真实通勤时间。GTFS 能把"30 分钟可达"算成真的。

**已试过**：valleymetro.org 直连/代理/浏览器都是 **403 + Cloudflare 挑战未通过**。
**提示**：transitfeeds.com 或 mobilitydatabase.org 这类镜像通常没有反爬。

---

### 3. 村庄级 ACS 人口数据 ⭐⭐

**要什么**：Phoenix **15 个 urban village**（或至少 12 个模拟区对应的 zip code）的：总人口、家庭收入中位数、65 岁以上比例、**无车家庭比例**。

**入口**（都免 key）：
- https://censusreporter.org/ → 搜 "Phoenix" → 选 urban village 或 ZCTA
- 或 https://data.census.gov/ 选 ACS 5-year，地理层级选 **ZCTA** 或 **Place**

**为什么重要**：现在只有**城市级** ACS（人口 1,673,122 / 收入 $85,246 / 65+ 12.9% / 无车 7.42%），**区级分布仍是假设**。区级真实数据会让公平分析可信得多。

**已试过**：Census Reporter API 取到了城市级；区级需要逐个 ZCTA 抓 + 做 ZCTA→区 的映射，工作量大但可做。
**最小可用版本**：只要给 10–15 个 Phoenix ZIP 的上述四个数就行（85003/85006/85008/85009/85015/85017/85031/85033/85035/85041/85051…）。

## 二、中优先级（影响某一部分论证）

### 4. Phoenix 本地冷却中心的**运营成本/容量** ⭐⭐

**要什么**：任意一个 Phoenix（或 Maricopa 县）冷却中心的：日接待容量、人员配置、开放一季的预算/成本。

**入口**：Phoenix 市预算文件（Budget Book）、2026 Heat Response Plan 附件、ARPA 支出报告。

**为什么重要**：现在只有芝加哥 Pilsen 的量级参照，**不能当凤凰城报价**。没有成本就只能比"人次"，不能比"钱"。

---

### 5. 移动/临时降温设施的真实案例 ⭐

**要什么**：任何城市用**移动降温车 / 喷雾站 / 临时纳凉点**的报告，含部署方式、服务人数、成本。

**入口**：搜 "mobile cooling center" "cooling bus" "heat relief trailer" + city。

**为什么重要**：题目问的就是"移动枢纽"，我们目前没有同类实证可比。

---

### 6. 热浪健康结局数据（可选）⭐

**要什么**：Maricopa 县的**热相关死亡/急诊**年度报告（2023/2024/2025）。

**入口**：https://www.maricopa.gov/1858/Heat-Surveillance （找 "Yearly mortality reports"）
**注意**：我们已有 2023 冷却中心调查 + 方法学白皮书，缺的是**逐年死亡数字**。

**为什么重要**：只能用于背景陈述，**不能写因果**（记录死亡 ≠ 设施效果）。优先级低。
